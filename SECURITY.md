# Security Policy

## Supported Versions

`squashfs-mount` is no longer under active development, with version 1.1 being the last MAJOR.MINOR release.

The `squashfs-mount` tool is now part of the [`eth-cscs/uenv`](https://github.com/eth-cscs/uenv) project.
Please check whether the issue is also present there, and submit reports to [the uenv security page](https://github.com/eth-cscs/uenv/security)

We will add security fixes to 1.1 as patch releases of squashfs-mount on a best-effort basis.

## Reporting a Vulnerability

Report the vulnerability at the [squashfs-mount security page on GitHub](https://github.com/eth-cscs/squashfs-mount/security)

We will reply as quickly as possible, and fix accepted issues withing 90 days.
